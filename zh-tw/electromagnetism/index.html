古典電磁學描述電場與磁場、它們的來源、對物質施加的力，以及它們的傳播。當元件尺寸相較於相關波長很小時，電路模型會近似這些場。高頻互連需要場模型或傳輸線模型，因為電壓與電流不再同時於各處變化。

電荷、電流、場與力 #

電荷守恆。電荷密度 ρ 描述每單位體積的電荷，而電流密度 J 描述每單位面積的電荷流動。其局部連續性關係為：

text 
∂ρ/∂t + ∇ · J = 0

電場 E 無論電荷是否移動都會對電荷施力。磁場 B 會貢獻與速度相依的力。兩者共同形成洛倫茲力：

text 
F = q(E + v × B)

磁力項垂直於速度，因此會改變方向，但本身不做機械功。電力項可以向電荷傳遞能量或從電荷取得能量。在導體中，電場驅動電荷載子，因而產生電流；材料特性與幾何形狀決定所產生的巨觀電阻。

微分形式與積分形式的 Maxwell 方程式 #

使用 SI 單位、含來源的真空 Maxwell 方程式如下：

text 
∇ · E = ρ/ε₀                 ∮ E · dA = Qenclosed/ε₀
∇ · B = 0                    ∮ B · dA = 0
∇ × E = -∂B/∂t              ∮ E · dl = -dΦB/dt
∇ × B = μ₀J + μ₀ε₀∂E/∂t    ∮ B · dl = μ₀I + μ₀ε₀dΦE/dt

微分形式描述某一點的場行為。積分形式將封閉表面或迴路上的場，與所包圍的電荷、電流或變化中的磁通量關聯起來。高斯電定律將電散度與電荷關聯。高斯磁定律表示在古典理論中，磁通量沒有來源或匯。法拉第定律將環流電場與變化中的磁通量關聯。含 Maxwell 位移電流項的安培定律，將環流磁場與傳導電流及變化中的電通量關聯。

在散度定理與 Stokes 定理所要求的正則性條件下，積分方程式由微分方程式推導而來。介面邊界條件則可藉由將高斯表面或迴路縮小並跨越材料邊界推導；表面電荷與表面電流隨後可以在選定的場分量中造成不連續。

感應與電磁波 #

法拉第感應解釋發電機、變壓器與電感器。穿過電路的磁通量變化會產生電動勢：

text 
emf = -dΦB/dt

負號表達楞次定律：感應反應會抵抗造成它的磁通量變化。互感透過共享磁通量耦合電路，而自感則將電路變化中的電流與其自身感應電壓關聯。

在無來源、均勻的真空中，對 Maxwell 方程式取旋度可得：

text 
∇²E = μ₀ε₀ ∂²E/∂t²
∇²B = μ₀ε₀ ∂²B/∂t²

這些波動方程式以 c = 1/√(μ₀ε₀) 的速度傳播。真空中的平面波具有彼此垂直的 E、B 與傳播方向。材料介電率、磁導率與導電率會改變相速度、衰減、反射與色散。

能量、Poynting 流與阻抗 #

真空電磁能量密度為：

text 
u = (ε₀|E|² + |B|²/μ₀) / 2

Poynting 向量給出每單位面積的功率流：

text 
S = E × H

Poynting 定理平衡減少的場能量、向外的能量通量，以及對電荷做的功。這個模型對電路很有用，因為功率是透過導體周圍的場抵達負載，而不是將電子視為以訊號速度沿電線攜帶能量的封包。

波阻抗關聯電場與磁場的大小。在真空中，Z₀ = √(μ₀/ε₀)，約為 377 歐姆。傳輸線則具有由導體幾何形狀與材料特性決定的特性阻抗。不匹配會造成反射；匹配來源、線路與負載阻抗可以控制這些反射。

輻射與模型限制 #

加速中的電荷與隨時間變化的電流分布可以輻射。天線幾何形狀決定近場如何耦合至儲存的電場與磁場能量，以及遠場如何攜帶能量離開。慣性參考系中以恆定速度移動的電荷，不會僅僅因為移動而輻射。

Maxwell 方程式是古典的。狹義相對論關聯不同慣性參考系之間的電場與磁場，而量子電動力學描述它們與物質的量子交互作用。
