util-linux 是一組系統工具集合，由獨立的上游專案維護。它為區塊裝置、掛載、終端機、工作階段、命名空間、資源控制與資料格式化提供介面。發行版可以將工具拆分到不同套件中，因此已安裝的命令取決於套件封裝政策。

操作邊界 #

修改分割區、掛載、交換空間、裝置狀態、程序憑證或命名空間的命令需要適當權限。變更狀態前先檢查狀態，使用 UUID 或 /dev/disk/by-id 等穩定屬性識別裝置，並確認目標未掛載且未被使用中。

此專案涵蓋多個核心介面：

  • lsblk、blkid、blockdev、fdisk 與 wipefs 檢查 sysfs、裝置 節點、ioctl 與磁碟上的簽章；
  • mount、umount、findmnt 與 fsfreeze 操作 VFS 掛載 API 以及 /proc/self/mountinfo；
  • unshare、nsenter、setpriv、prlimit、taskset 與 chrt 設定 程序命名空間、憑證、資源限制、親和性與排程器；
  • agetty、script、setterm 與 wall 操作終端機與登入記錄。

確切的命令集合取決於 util-linux 的建置設定與發行版套件封裝方式。依賴較新的選項前，請使用 command --help、命令的 man 頁面、發行版套件中繼資料，或個別命令的 --version 輸出進行確認。

常見工作流程 #

lsblk --fs、blkid、findmnt 與 mountpoint 可以在不變更儲存裝置的情況下檢查其狀態：

sh 
lsblk --json --output NAME,PATH,SIZE,FSTYPE,UUID,MOUNTPOINTS
findmnt --json --output SOURCE,TARGET,FSTYPE,OPTIONS
blkid --probe --usages filesystem /dev/disk/by-id/example

由於 util-linux 會加入新的資訊，預設輸出會變更，因此請在指令碼中指定欄位。在支援的情況下，優先使用 --json、--pairs 或 --raw；解析人類可讀的診斷訊息時，請設定 LC_ALL=C。不要將對齊後的預設表格解析為穩定介面。

fdisk、cfdisk 與 sfdisk 會修改分割區表。使用 sfdisk --dump 儲存目前配置，並在寫入前透過大小、型號、序號與穩定路徑驗證裝置。預期的分割區表變更後，partx 會要求核心新增或移除分割區對映；它不會編輯磁碟上的分割區表。mkswap 準備交換區域，接著由 swapon 啟用，並由 swapoff 停用。

unshare、nsenter、setpriv、runuser、setarch 與 taskset 會影響執行內容。變更命名空間或親和性不會授予權限；程序能執行的操作仍由 capabilities、使用者對映與 cgroup 原則決定。

sh 
unshare --user --map-root-user --mount-proc sh
nsenter --target "$pid" --mount --uts --ipc --net --pid
script --log-out session.typescript --log-timing session.timing

nsenter 會加入現有程序所使用的選定命名空間，因此需要具備檢查並進入這些命名空間的權限。非特權使用者命名空間中 unshare 的可用性由核心與本機安全原則控制。

script、scriptreplay 與 scriptlive 可以擷取終端機工作階段。記錄的輸入可能包含憑證或其他機密，因此檔案需要採用與其內容相符的存取控制。
