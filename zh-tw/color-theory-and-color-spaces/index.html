色彩理論與色彩空間

當軟體需要將數字映射為可見輸出時，色彩理論便具有實際意義。其底層物理過程很簡單，但知覺模型並不簡單。

視錐細胞反應 #

人類視覺使用三類視錐細胞，通常根據其對長、中、短波長的敏感度分別稱為 L、M 和 S。

  • L 視錐細胞在約 564–580 nm 處反應最強。
  • M 視錐細胞在約 534–545 nm 處反應最強。
  • S 視錐細胞在約 420–440 nm 處反應最強。

不同人的視錐細胞分布存在差異，因此相同的光譜可能產生略有不同的知覺結果。L 視錐細胞和 M 視錐細胞的比例在個體之間差異很大，而 S 視錐細胞只占總數的一小部分，通常約為 2%。

大腦不會還原出單一波長，而是根據視錐細胞反應的模式和強度估計顏色。在理想條件下，人類視覺在紫外線區域可延伸到約 310 nm，在近紅外線區域可延伸到 1100 nm，但這些界限並不明確。

加法混色 #

光源的光會相加。650 nm 的光束和 540 nm 的光束不會合併成一束具有平均波長的新光束；它們仍會以各自的波長刺激眼睛。

因此，兩個不同的光譜可能看起來完全相同。知覺上的匹配不要求物理光譜完全一致，只要求視錐細胞的反應相同。

洋紅色是典型範例：它是有效的知覺顏色，但在可見光譜中並不存在對應的單一波長。

色彩空間 #

色彩空間是一種表示色彩值的座標系，同時包含對色域和傳遞特性的定義。

sRGB #

sRGB 是 Web 和許多 UI 工具組的預設色彩空間。它基於 RGB 原色和一條非線性傳遞曲線，因此便於裝置處理，但在知覺上並不均勻。

HSL #

HSL 將色相、飽和度和明度分離開來，因此在「選擇更偏紅的顏色」或「降低鮮豔度」等任務中，比直接使用原始 RGB 更容易理解。代價是，數值上相等的步長並不對應知覺上相等的步長。

HSV #

HSV 類似於 HSL，但以明度或亮度取代明度。它通常適用於色彩選擇器，因為它符合使用者描述類似顏料的調整方式。

漸層 #

在 RGB 中進行線性插值很簡單，但由於 RGB 在知覺上並不均勻，因此中間色經常顯得混濁。

如果目標是實現平滑的視覺過渡，那麼插值空間比公式本身更重要。漸層應當在座標軸更符合人類知覺的空間中進行評估，這樣中間顏色才會顯得間隔均勻。

參考資料 #

  • CIE 視錐細胞反應資料
