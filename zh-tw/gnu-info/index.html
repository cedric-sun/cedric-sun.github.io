GNU Info 是用於閱讀由 Texinfo 產生之手冊的終端機閱讀器。它不是用來閱讀線性文字檔案的 分頁器：Info 檔案包含具名節點，並透過選單、交叉參照以及 Next、Prev 和 Up 指標相互連結。已安裝的手冊可能拆分為檔案系統中的多個壓縮檔案，但 Info 會將其呈現為 一本手冊。

從手冊樹狀結構開始 #

執行不帶引數的 info 以開啟目錄節點，也就是已安裝的手冊樹狀結構。執行 info coreutils 或 info '(coreutils)Top' 以開啟具名手冊與節點。

sh 
info
info bash
info '(gitman)git-config'

引數語法為 '(file)node'；請將其加上引號，避免 shell 解讀特殊字元。找不到手冊表示 提供其 Info 檔案的套件尚未安裝，或其 Info 目錄不在搜尋路徑中。

依循節點而非頁面瀏覽 #

使用節點結構進行針對性閱讀：

按鍵動作
n, p, u依循 Next、Prev 或 Up 指標。
t, d前往手冊的 Top 節點或目錄節點。
m從目前的選單中選取項目。
f依循交叉參照。
g依名稱前往節點。
l依已瀏覽節點的歷程返回。

n 和 p 依循節點階層，而 [ 和 ] 則按照手冊的循序節點順序移動。前者適合用於 結構導覽，後者適合像閱讀書籍一樣依序閱讀；兩者可能到達不同的節點。

閱讀、搜尋與返回 #

SPC 會向前捲動，並可能在節點結尾繼續前往下一個節點；DEL 或 Backspace 會向後 捲動。C-v 會向前捲動，但不會離開目前節點。b 和 e 會移至節點的開頭與結尾。

使用 s 向前搜尋，並再次按下 s 重複搜尋。i 會搜尋手冊索引；搜尋命令或選項名稱 時，索引通常比全文搜尋更精確。依循交叉參照後，使用 l 可循節點歷程返回。

按下 H 可查看閱讀器內建的按鍵綁定說明，按下 q 則可結束。Info 採用 Emacs 風格的表示法：C-x 表示 Ctrl+x，M-x 表示 Meta+x。在將 Alt 對應至 Meta 的 終端機上，M-x 即為 Alt+x。 M-x 也可依名稱執行命令；當終端機或本機設定變更按鍵綁定時，此功能相當實用。

留意閱讀器差異 #

獨立的 info 程式與 Emacs Info 提供相似的節點概念，但按鍵綁定、顯示、自訂方式與 滑鼠行為可能不同。less 等分頁器捲動的是位元組串流；Info 則保留節點連結、選單、 歷程與索引。請使用 info --help、H 或已安裝的 Info 手冊，確認目前系統上閱讀器 提供的按鍵綁定。
