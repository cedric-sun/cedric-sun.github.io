Wayland 顯示伺服器

Wayland 是一種顯示通訊協定，專為同一核心上的本機用戶端與合成器所設計。 工具組的 Wayland 後端會使用 libwayland-client 連線至 Unix 通訊端，其位置通常是 $XDG_RUNTIME_DIR/$WAYLAND_DISPLAY，例如 /run/user/1000/wayland-0。

通訊協定模型 #

用戶端與合成器會針對表面、緩衝區和輸入基座等編號物件，交換具型別的請求與事件。 XML 通訊協定定義會產生封送處理存根。用戶端會將內容算繪到共享記憶體或 DMA-BUF 支援的緩衝區，再將這些緩衝區提交給合成器；合成器會組合表面，並控制 輸出裝置與輸入。因此，Wayland 合成器結合了 X11 伺服器、視窗管理員及合成器中 過去經常彼此分離的角色。

核心通訊協定沒有 TCP 傳輸機制；遠端顯示解決方案會提供自己的傳輸與安全模型。 執行階段目錄和顯示通訊端屬於安全邊界，因此不應將其掛載至不受信任的容器中。

Xwayland 相容性 #

Xwayland 會執行一個巢狀置於 Wayland 合成器下的 X 伺服器。它透過 X11 Unix 通訊端接受舊版 X11 用戶端，並將其視窗轉換為 Wayland 表面。原生 Wayland 應用程式不需要 Xwayland，但對於使用 libX11 或其他僅支援 X11 的工具組後端的 應用程式而言，Xwayland 仍相當重要。
