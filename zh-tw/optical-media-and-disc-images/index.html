光學媒體與光碟映像

光學媒體、磁區格式、檔案系統與映像檔是不同的層次。可掛載的 .iso 可以重現資料磁區，但可能省略音訊軌、工作階段邊界、子通道與錄製屬性。因此，映像格式必須依照預定工作選擇：檔案散布、開機、模擬或保存。

軌道、標記與讀取 #

CD、DVD 和 Blu-ray Disc (BD) 沿著螺旋軌道儲存其程式區。聚焦雷射從內側程式區向外側追蹤該螺旋，光學讀取頭根據反射光的變化產生訊號。由於圓周朝向外緣逐漸增大，旋轉通常採用恆定線速度或分區策略。

壓製的唯讀光碟會在聚碳酸酯中模製出浮雕圖樣，並加入反射層。「凹坑」與「平地」描述的是實體層級，而不是字面上的 0 與 1 儲存單元。轉換與游程長度會產生通道訊號，再由光碟機進行解碼與錯誤更正。CD 使用 Eight-to-Fourteen Modulation 與 Cross-Interleaved Reed–Solomon Code；只有在這些較低層完成解碼後，才會出現磁區層級的位元組。

不同家族的實體尺寸不同。標準 CD 是厚度 1.2 mm 的聚碳酸酯光碟，使用近紅外線雷射讀取，軌道間距為 1.6 µm。DVD 透過波長較短的紅色雷射、較小的標記與間距，以及可選的第二層來提高密度。BD 使用藍紫色雷射，軌道間距約為 0.32 µm。共用螺旋概念並不代表它們的光學系統、通道編碼或磁區格式可以互換。

壓製、可錄製與可重寫媒體 #

製造與錄製方式決定標記如何形成：

  1. 壓製的唯讀媒體將母版浮雕複製到模製基板中。電鑄會將顯影後的玻璃母盤轉換為金屬壓模；經過模製、金屬化、接合、塗漆與標籤處理後，製成完成的光碟。
  2. 可錄製媒體只能寫入一次。CD-R 與傳統可錄製 DVD 格式會改變有機染料，而常見的 BD-R 設計則使用無機錄製層。寫入後的對比會模擬相容光碟機預期的讀取行為。
  3. 可重寫媒體使用可逆錄製層，通常是相變合金。加熱會使區域在反射率不同的狀態之間切換。

可錄製光碟包含預先形成的導槽，用於引導錄製器，並攜帶格式特有的定址或計時資訊。可重寫並不代表具備類似磁碟的原子更新：封包寫入軟體、缺陷管理、檔案系統規則與媒體結束化仍會限制變更。僅憑材料顏色無法識別配方，也無法預測保存壽命。

軌道與工作階段 #

CD 軌道是單一連續串流，具有宣告的類型，例如 CD Digital Audio (CD-DA) 或 CD-ROM 資料模式。一張光碟可以包含多個軌道。Mixed-mode 與 CD Extra 配置會依照特定排序規則組合音訊與資料；軌道控制旗標會告知播放器如何解讀它們。

工作階段會將一次錄製操作中寫入的一個或多個軌道分組，並加入導入區與導出區結構。多工作階段讀取器使用工作階段中繼資料定位軌道並選擇檔案系統檢視。追加工作階段可以公開一棵參照先前工作階段資料的新目錄樹，但不會重寫已錄製的磁區。只複製檔案會失去這些關係。

規格家族與磁區 #

以顏色命名的 Rainbow Books 定義 CD 家族格式：

  • Red Book 規定 CD-DA。
  • Yellow Book 規定 CD-ROM 模式。
  • Orange Book 涵蓋可錄製 CD 與可重寫 CD。
  • Green Book、White Book 與 Blue Book 分別定義 CD-i、Video CD 與 Enhanced CD 應用程式。

ECMA-130 與 ISO/IEC 10149 標準化 CD-ROM 錄製與磁區組織，而 IEC 60908 涵蓋 CD-DA。ISO 9660 在 CD-ROM 磁區上定義獨立的磁區與檔案結構。DVD Forum 規格與 Blu-ray Disc Association 的規格書分別定義各自的媒體；DVD 與 BD 並不是 Rainbow Book 格式。

傳統解碼後的 CD 磁區包含 2,352 個位元組。CD-DA 將全部 2,352 個位元組用於音訊取樣。CD-ROM Mode 1 磁區提供 2,048 個使用者資料位元組，其餘用於同步、定址、錯誤偵測及額外錯誤更正。Mode 2 格式會以不同方式劃分這些位元組。因此，「磁區大小」必須說明是指通道資料、原始解碼後磁區，還是檔案系統可見的使用者資料。

檔案系統與開機層 #

光學檔案系統會使用使用者資料磁區；它們不會定義光學標記或所有軌道中繼資料。

ISO 9660 與擴充 #

ISO 9660 源自 High Sierra 格式，定義可攜式唯讀磁區與目錄結構。其基本交換層級限制名稱與目錄組織。Rock Ridge 在 System Use 欄位中記錄面向 POSIX 的名稱、連結、權限與裝置資訊。Joliet 加入 Microsoft 定義的 Unicode 目錄樹。讀取器必須明確支援所選擇的擴充。

UDF #

Optical Storage Technology Association 的 Universal Disk Format (UDF) 專門化了 ECMA-167 定義的磁區與檔案結構。UDF 支援 DVD、BD、封包寫入與一次性錄製所需的媒體與更新模型。版本與媒體設定檔的相容性很重要，因為讀取器支援 UDF 並不代表支援每一個版本或功能。

El Torito 與混合檢視 #

El Torito 將韌體可探索的開機記錄與開機目錄加入 CD-ROM 磁區。目錄項目會識別軟碟模擬、硬碟模擬或無模擬開機映像。因此，可開機性取決於記錄、目錄值、映像位元組與配置位置，而不只是掛載目錄中可見的檔案。

混合光碟可以在 ISO 9660、Joliet、Rock Ridge 與 UDF 描述元之間共用檔案資料，使不同系統選擇不同的目錄檢視。有些安裝程式映像也會將光學開機中繼資料與用於 USB 開機的 MBR 或 GPT 配置結合。重建一個可見的檔案系統可能會捨棄其他檢視與開機路徑。

映像表示 #

映像擷取的是光碟中選定的一層：

  • ISO 映像通常儲存資料軌道中的 2,048 位元組邏輯磁區。它可以包含 ISO 9660、UDF、混合磁區或其他區塊配置；檔案副檔名無法識別檔案系統。
  • 原始 CD 軌道映像通常儲存 2,352 位元組磁區。原始磁區保留較多模式特有的位元組，但其本身仍不會描述軌道邊界、預間隙、控制旗標或工作階段。
  • BIN/CUE 集合將一個或多個二進位軌道檔案與描述軌道類型、順序、索引與間隙的 cue sheet 配對。保存需要兩個部分。
  • NRG 等容器格式可以儲存軌道資料與廠商特有的配置中繼資料。哪些中繼資料能在轉換後保留，取決於工具支援情況。

子通道資料是與 CD 框架相關聯的另一個串流。部分複製保護、索引、CD-Text 與計時用途需要特定子通道，但一般 ISO 或 BIN/CUE 工作流程可能會省略它們。僅憑副檔名無法證明完整性；映像文件必須說明磁區模式、子通道處理、光碟機行為與讀取錯誤原則。

檢查、掛載與擷取 #

應先檢查再掛載，因為掛載會公開一個檔案系統檢視，並可能隱藏其他軌道。libcdio 工具可以檢查 CD 與 ISO 9660 結構：

sh 
cd-info --no-device-info image.cue
iso-info -i installer.iso
iso-read -i installer.iso -e README.txt -o README.txt
isosize --sectors installer.iso

已安裝的版本可能不同，因此指令碼應查閱每個指令的手冊，而不是假設選項存在。使用格式感知的讀取器擷取資料，可以將來源保持為唯讀，並避免需要核心掛載。

Linux 可以透過迴圈裝置掛載相容的邏輯映像：

sh 
sudo mount -o loop,ro installer.iso /mnt/iso

macOS 可以使用以下指令連接可掛載映像：

sh 
hdiutil attach -readonly installer.iso

掛載只能證明某個檔案系統剖析器接受了某個檢視；它不能驗證音訊、工作階段、開機路徑、原始錯誤更正位元組或子通道。

完整性與可重現性 #

可辯護的映像製作流程會記錄：

  1. 光碟識別資訊、可見狀態，以及光碟機型號與韌體；
  2. 映像製作工具、版本、指令、磁區模式與重試原則；
  3. 軌道、工作階段與子通道中繼資料；
  4. 每個映像與附帶中繼資料檔案的加密雜湊；
  5. 讀取錯誤、復原磁區，以及重複讀取是否一致。

雜湊一致可以保護擷取後的檔案，但無法證明光碟機回傳了每一項實體特徵。若關注對象是可掛載的軟體散布物，邏輯映像便適用。若軌道語義、音訊、工作階段或模擬器行為很重要，則需要具備完整配置中繼資料的原始軌道。
