VNC 使用遠端畫面緩衝區協定傳輸遠端畫面緩衝區與輸入事件。它適合隔離的圖形桌面、由瀏覽器提供的工作階段，以及不應接收主機顯示器 socket 的容器工作負載。

伺服器與虛擬顯示器 #

Xvfb 是不具實體顯示器、在記憶體中運作的 X 伺服器；x11vnc 透過 VNC 共用現有的 X 顯示器，本身不會建立虛擬桌面。其他 VNC 伺服器，例如 TigerVNC 的 Xvnc，則會將 X 伺服器與 VNC 端點結合。noVNC 是 WebSocket 至 VNC 的用戶端，可讓瀏覽器透過相容的 Proxy 連線。

VNC 的驗證與加密方式取決於實作。伺服器只能透過已驗證且加密的通道公開，常見方式包括 VPN、SSH 通道，或具備 TLS 與存取控制的閘道。
