19 吋伺服器機櫃

19 吋機櫃標準化電信、運算、網路與音訊設備的前面板與安裝幾何尺寸。名義上的 19 吋尺寸描述安裝耳之間的面板寬度；它不指定機櫃寬度、導軌間距、設備深度、電力或冷卻。

機櫃單位、孔位模式與導軌 #

一個機櫃單位（U 或 RU）是 1.75 吋（44.45 mm）。一個 1U 間隔包含三個垂直間隔的安裝孔。中心到中心的模式在重複前依序為 0.625 吋、0.625 吋與 0.5 吋，因此可以透過較窄的間隙識別相鄰機櫃單位的邊界。請一致地標記導軌，因為跨越邊界安裝機箱會使後續每次安裝都偏移。

導軌使用帶有籠式螺帽的方孔、未攻牙的圓孔或攻牙孔。免工具滑軌硬體無法在所有模式之間互換。四柱機櫃會在前後導軌承載深型伺服器。雙柱中繼機架適合淺型設備，而深型或重型機箱需要製造商核准的層板或中央安裝套件。

設備深度與可用機櫃深度是分開的測量值。請檢查：

  • 前後導軌調整範圍。
  • 機箱深度加上連接器、電纜彎曲半徑與電源線。
  • 門、風扇與電纜管理的間隙。
  • 滑軌延伸距離與維修位置。
  • 側板、零 U PDU 與垂直電纜管理器造成的障礙。

負載、重心與錨定 #

機櫃的靜態額定值適用於已安裝且靜止的狀態。動態或運輸額定值會計入移動因素，可能低得多。地板負載、腳輪、調平腳、架高地板磚與地震要求會施加額外限制。

請將重型設備安裝在較低位置，因為較高的重心會增加傾覆力矩。除非機櫃製造商另有指定，否則一次只伸出一個滑動機箱。安裝耳會定位設備，但可能無法承載其全部重量；請安裝所有必要的導軌、後方支撐與扣件。

依安裝說明與當地要求錨定或穩定機櫃。連接相鄰機櫃可以改善對齊，但需要錨定時不能取代地板或牆面錨定。移動已裝滿的機櫃前，請另行驗證運輸負載。

配電與接地 #

電力規劃應從分支電路開始，而不是從 PDU 插座數量開始。計算穩態負載、啟動或湧入行為、電源供應器效率，以及適用電氣法規所要求的連續負載限制。不要將設備銘牌最大值總和視為電路或冷卻設計有效的證明；請測量具代表性的工作負載並保留有文件記錄的餘裕。

只有在連接至獨立故障域時，冗餘裝置電源供應器才會改善可用性。在基礎設施允許時，將它們連接至分開的機櫃 PDU、分支電路、UPS 路徑與上游來源。確認任一存活路徑都能承載故障轉移負載。計量 PDU 公開電流或功率，而切換式 PDU 也允許受控的插座操作。

UPS 會在停電期間橋接並在其設計限制內調節電力。運作時間取決於實際負載、電池健康狀態、溫度與轉換模式。發電機與自動切換開關可處理較長事件，但也會引入自身的切換與維護行為。

保護接地會連接裸露導電部件，使故障能操作保護裝置。請遵循機櫃與設施的接地設計；訊號參考與保護接地不可互換。不要為了解決資料路徑雜訊問題而移除安全接地。

氣流與熱管理 #

多數伺服器與網路設備使用前進後出的氣流，而有些網路裝置提供反向氣流版本。混合方向可能使熱排氣再循環至進氣口。調整列與封閉系統的方向，讓冷供氣抵達進氣口，並讓熱氣在不短路的情況下回流。

封板會關閉未使用的機櫃單位開口，因為開放間隙會允許排氣再循環。刷毛板與密封地板開口可減少電纜周圍的旁通。機櫃門需要足夠的自由面積，而濾網需要維護週期。相較於室內平均溫度，機櫃進氣溫度更適合偵測局部熱點。

冷卻容量必須符合電氣熱負載：幾乎所有輸入功率都會在室內變成熱。高密度設備可能在耗用實體空間或 PDU 插座前，就超過機櫃規劃的熱容量。請同時監控進氣溫度、風扇狀態、節流與 PDU 負載。

佈線、維修間隙與標籤 #

可行時分離電力與資料路徑，遵守光纖與銅纜彎曲半徑，並讓電纜遠離風扇進氣口與滑動機構。電纜管理臂需要足夠鬆弛量，以便完全延伸而不拉扯連接器。多餘電纜應以可預測方式佈設，而不是塞入氣流路徑。

為門、推車、起重設備與元件更換預留前後間隙。有些伺服器需要完全抽出才能更換內部零件，因此走道寬度與機櫃錨定都是可維修性的一部分。

以穩定識別碼標示每條電力、網路、儲存與主控台連線的兩端。在資產清冊中記錄機櫃、單位位置、裝置、連接埠、PDU 插座與上游電路。機櫃單位座標描述實體位置；它不能取代電氣、網路或相依性文件。
