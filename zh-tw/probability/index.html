機率描述模型中的不確定性。它不會建立因果關係：相關變數可能具有強烈的條件關係，但其中任一者都不一定造成另一者。

隨機變數與動差 #

隨機變數會將結果映射至數值。其分布會將機率質量或密度指定給這些數值。對純量隨機變數 \(X\) 而言，期望值與變異數為：

\[ \mathbb{E}[X], \qquad \operatorname{Var}(X) = \mathbb{E}[(X-\mathbb{E}[X])^2]. \]

標準差是變異數的平方根。對隨機向量 \(X\) 而言，平均值是向量，而共變異數是矩陣：

\[ \operatorname{Cov}(X) = \mathbb{E}[(X-\mu)(X-\mu)^\mathsf{T}]. \]

共變異數會量測分布中的線性共同變化；它本身無法識別因果機制。

條件機率與貝氏定理 #

對於 \(P(B) > 0\)，

\[ P(A \mid B) = \frac{P(A \cap B)}{P(B)}. \]

貝氏定理會反轉條件關係：

\[ P(A \mid B) = \frac{P(B \mid A)P(A)}{P(B)}. \]

機器學習分類器通常會估計 \(P(y \mid x)\)。這類估計需要校準與驗證；只有在經驗頻率支持該解讀時，呈現為機率的分數才有用。

大數法則指出，當樣本數增加時，適當的獨立同分布觀測值之平均會收斂至期望值附近。它不會使小樣本具代表性、不會造成結果交替，也不會修正系統性的抽樣偏差。
