電路分析描述電場如何移動電荷，以及如何儲存或耗散能量。電壓是電位差，電流是單位時間的電荷流量，而功率是能量傳遞速率：

text 
V = I R
P = V I

歐姆定律適用於線性電阻，不適用於每個元件。實際設計也必須符合電壓、電流、功率、溫度、頻率與暫態額定值。

電阻、電容與電感 #

電阻器將電能以熱的形式耗散。電阻以歐姆為單位，而電導是其倒數，以西門子為單位。電阻率是材料屬性；元件的電阻也取決於其幾何形狀與溫度。

電容器將能量儲存在電場中：

text 
C = Q/V
i = C dv/dt
EC = C V²/2

在理想模型中，電容電壓不能瞬間改變，因為瞬間變化需要無限大的電流。在串聯 RC 電路中，電壓以時間常數 τ = RC 指數趨近最終直流值。實際電容器會加入等效串聯電阻、漏電、介電吸收，以及隨電壓或溫度變化的電容量。

電感器將能量儲存在磁場中：

text 
v = L di/dt
EL = L I²/2

在理想模型中，電感電流不能瞬間改變。串聯 RL 電路的時間常數為 τ = L/R。實際電感器會加入繞線電阻、寄生電容、磁芯損耗與飽和電流限制。中斷電感電流可能產生高電壓，因此線圈與繼電器通常需要續流二極體或其他箝位電路。

在正弦角頻率 ω 下，阻抗結合電阻與電抗：

text 
ZR = R
ZC = 1/(jωC)
ZL = jωL

因此幅值與相位會隨頻率變化。在理想直流穩態下，電容器表現為開路，而電感器表現為短路；兩種近似都無法描述啟動或高頻行為。

基爾霍夫電流定律平衡節點上的電流，而基爾霍夫電壓定律平衡迴路周圍的電位變化。戴維寧與諾頓等效電路將線性二端網路化簡為電源與阻抗，讓負載與偏壓計算更容易。

邏輯電位、上拉電阻與雜訊裕度 #

數位邏輯將電壓範圍映射至邏輯零與一。資料表會指定最大輸入低電壓 VIL、最小輸入高電壓 VIH、最大輸出低電壓 VOL 與最小輸出高電壓 VOH。最壞情況的直流雜訊裕度為：

text 
low margin  = VIL(max) - VOL(max)
high margin = VOH(min) - VIH(min)

電源變動、接地偏移、串擾、終端與邊緣速率會降低可用裕度。TTL、LVTTL、CMOS 與 SSTL 等邏輯系列名稱不保證電氣相容性；請比較實際的輸入、輸出、電流與時序規格。

未驅動的輸入沒有保證狀態。上拉或下拉電阻為它提供預設電位，同時允許主動驅動器覆寫電阻。開漏與開集極輸出需要上拉，且裝置只宣告低狀態，因此可以共享線路。推挽輸出會主動驅動兩種狀態，除非協定避免匯流排爭用，否則不得彼此連接。

高阻抗輸出會在電氣上將驅動器與共享匯流排斷開。RESET_n 或 CS# 等低有效名稱描述有效極性，而不是電壓標準。DDR 等源同步介面會隨資料分配選通，因為接收器時序取決於相對邊緣位置，而不只是遠端系統時鐘。

PN 接面、二極體與整流 #

施體摻雜在 n 型矽中提供可移動電子，而受體摻雜在 p 型矽中提供可移動電洞。PN 接面兩側的擴散會留下固定的離子化摻雜物，形成耗盡區與內建電場。

正向偏壓降低接面障壁並允許大量電流。反向偏壓拓寬耗盡區，並在崩潰前允許漏電。常見的定電壓二極體模型適合粗略分析，但二極體電流會隨接面電壓呈指數變化，且強烈受溫度影響。

半波整流器在一種輸入極性期間導通。橋式整流器使用兩個半週期，但導通路徑中會產生兩個二極體壓降。儲能電容在波峰之間提供負載電流以降低漣波；電源、二極體、電容漣波額定值、湧入電流與穩壓器都必須依產生的脈衝電流選定規格。

齊納與雪崩二極體刻意在反向崩潰區工作，以進行箝位或提供參考。崩潰不會限制電流，因此需要串聯阻抗。LED 將載子復合轉換為光，而光電二極體將吸收的光子轉換為電流；光譜響應與偏壓取決於裝置結構。

BJT 與 MOSFET 操作區域 #

NPN 雙極性接面電晶體具有截止、正向主動、飽和與反向主動區域。類比放大通常將裝置偏壓在正向主動區，其中集極電流與基極—射極電壓相關，並在有限範圍內約為基極電流的 β 倍。切換操作會在截止與飽和之間驅動電晶體。由於 β 會隨電流、溫度與裝置而變化，開關設計會使用強制基極電流，並檢查飽和電壓與儲存時間。

在長通道模型中，增強型 MOSFET 具有截止、三極體/線性與飽和區域。其術語與 BJT 切換不同：用作閉合開關的 MOSFET 工作在低電阻三極體區，而不是 MOSFET 飽和區。閘極臨界電壓只標示資料表中初始導通的測試條件，不保證低導通電阻。

MOSFET 閘極消耗很少直流電流，但具有電容量。驅動器必須足夠快速地移動指定閘極電荷，以控制切換損耗。設計必須檢查實際閘極電壓下的 RDS(on)、汲極電壓與電流限制、安全工作區、體二極體行為、熱阻與切換暫態。CMOS 邏輯結合 n 通道與 p 通道裝置以降低靜態電流，而電容量充電會產生動態功率。

接地、電源與量測安全 #

接地是參考節點，不是無限大的電流匯。保護接地、機殼、類比接地、數位接地與訊號回流具有不同角色。回流電流會沿著阻抗最低的路徑流動；在高頻下，該路徑可能不同於電阻最低的路徑。因此，佈局應保留短回流路徑，並避免迫使敏感訊號共用大電流造成的電壓降。

電源輸入需要限流、負載接腳附近的去耦、整體能量儲存、必要時的反極性保護，以及依故障電流選定規格的導體。保險絲能保護配線並降低火災風險，但不會使高電壓電路可安全觸摸。

探測電路前：

  • 驗證電表、探棒、絕緣與來源適用的類別額定值。
  • 不需要通電量測時，先斷電並釋放儲存的能量。
  • 記住工作台示波器探棒的接地通常連接至保護接地；將它夾到帶電節點可能造成短路。
  • 對浮動或高側節點，使用專為此用途設計的差動或隔離量測方法。
  • 將電流量測串聯，並在連接前確認電表導線插入正確且具保險絲的輸入端。

市電、高能量電池與帶電電容器可能造成致命電擊、電弧或火災。這些系統需要適用的安全標準、隔離與合格程序，而不是臨時的麵包板工作流程。
