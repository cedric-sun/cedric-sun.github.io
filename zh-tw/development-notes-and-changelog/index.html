VS Code 虛擬空格 #

VS Code 多年來一直不支援虛擬空格。Issue microsoft/vscode#13960 自 2016 年起追蹤這項功能，直到該功能最終於 2024 年獲得解決。

使用 Libtool 進行靜態連結 #

LT_INIT 用於設定專案建置其函式庫的方式。它不會控制可執行檔最終採用的連結器模式。

當 libtool 驅動連結步驟時，LDFLAGS=-static 會被轉送至命令列，但如果傳遞相依性只能以共用物件的形式提供，這並不能保證產生完全靜態的二進位檔。

sh 
/bin/sh ../libtool --silent --tag=CC --mode=link gcc ... -static -o file file.o seccomp.o libmagic.la -lm -lz

有用的檢查方法包括：

  • 使用 make -d 檢查實際的連結命令；
  • 對結果執行 ldd；
  • 在預期產生完全靜態的可執行檔之前，確認每個必要的函式庫都可作為靜態封存檔使用。
