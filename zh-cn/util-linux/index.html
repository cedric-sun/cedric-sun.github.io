util-linux 是一个系统工具集合，由一个独立的上游项目维护。它为块设备、挂载、终端、会话、命名空间、资源控制和数据格式化提供接口。发行版可以将这些工具拆分到不同的软件包中，因此已安装的命令取决于软件包策略。

操作边界 #

修改分区、挂载、交换空间、设备状态、进程凭据或命名空间的命令需要适当的权限。修改状态前应先检查当前状态，使用 UUID 或 /dev/disk/by-id 等稳定属性识别设备，并确认目标未被挂载且未处于活动使用状态。

该项目涉及多个内核接口：

  • lsblk、blkid、blockdev、fdisk 和 wipefs 检查 sysfs、设备 节点、ioctl 以及磁盘上的签名；
  • mount、umount、findmnt 和 fsfreeze 操作 VFS 挂载 API 以及 /proc/self/mountinfo；
  • unshare、nsenter、setpriv、prlimit、taskset 和 chrt 配置 进程命名空间、凭据、资源限制、CPU 亲和性和调度器；
  • agetty、script、setterm 和 wall 操作终端和登录记录。

确切的命令集合取决于 util-linux 的构建配置和发行版打包方式。在依赖较新的选项之前，请使用 command --help、命令的 man 页面、发行版的软件包元数据，或单个命令的 --version 输出进行确认。

常见工作流 #

lsblk --fs、blkid、findmnt 和 mountpoint 可以在不修改存储的情况下检查存储状态：

sh 
lsblk --json --output NAME,PATH,SIZE,FSTYPE,UUID,MOUNTPOINTS
findmnt --json --output SOURCE,TARGET,FSTYPE,OPTIONS
blkid --probe --usages filesystem /dev/disk/by-id/example

由于 util-linux 会不断添加信息，默认输出会发生变化，因此应在脚本中指定列。在支持的情况下，优先使用 --json、--pairs 或 --raw；解析面向人类的诊断信息时，应设置 LC_ALL=C。不要将对齐后的默认表格解析为稳定接口。

fdisk、cfdisk 和 sfdisk 会修改分区表。使用 sfdisk --dump 保存当前布局，并在写入前通过大小、型号、序列号和稳定路径验证设备。预期的分区表发生更改后，partx 会请求内核添加或删除分区映射；它不会编辑磁盘上的分区表。mkswap 准备交换空间，之后由 swapon 启用，由 swapoff 禁用。

unshare、nsenter、setpriv、runuser、setarch 和 taskset 会影响执行上下文。更改命名空间或 CPU 亲和性不会授予权限；进程能够执行的操作仍由 capabilities、用户映射和 cgroup 策略决定。

sh 
unshare --user --map-root-user --mount-proc sh
nsenter --target "$pid" --mount --uts --ipc --net --pid
script --log-out session.typescript --log-timing session.timing

nsenter 会加入现有进程所使用的指定命名空间，因此需要有权限检查并进入这些命名空间。非特权用户命名空间中 unshare 的可用性由内核和本地安全策略控制。

script、scriptreplay 和 scriptlive 可以捕获终端会话。记录的输入可能包含凭据或其他机密信息，因此文件需要采用与其内容相适应的访问控制。
