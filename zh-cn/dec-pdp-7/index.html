Digital Equipment Corporation (DEC) built its first computers 来自 cataloged logic modules rather than custom monolithic processor boards. Module packaging changed substantially between the laboratory products, System Modules, 和 FLIP CHIP cards, but the engineering method remained recognizable: combine standardized gates, flip-flops, pulse circuits, 和 drivers 通过 a wired backplane.

实验室模块 #

Engineers could patch modules together 在 a bench or install them in a rack chassis. Catalogs offered functional blocks such 作为 inverters, flip-flops, pulse amplifiers, delays, clocks, 和 power supplies in families intended for different switching rates.

Packaging a tested circuit 作为 a reusable block reduced the amount 的 transistor-level design required 用于 each installation. Front-panel patching remained bulky, however, so the format suited laboratories better than processors containing hundreds of repeated logic functions.

从系统模块到 FLIP CHIP #

System Building Blocks, later 称为 System Modules, moved circuits onto compact cards，使用 edge connectors. Cards plugged 到 sockets in a wire-wrapped backplane; the wrapped point-to-point wiring joined their pins 到 registers, counters, buses, and control paths. “Backplane” in this context means the connector field 和 its wiring, 不 a modern multilayer printed circuit board carrying a standardized bus.

FLIP CHIP packaging continued the card-and-backplane approach in a smaller form. DEC produced several electrically distinct series 用于 logic, timing, 和 peripheral interfaces. Colored extraction handles 和 printed type numbers helped technicians locate a module, 同时 maintenance 文档 traced signals between module pins. catalog unit might implement a few gates 或 one register bit, so a complete processor 函数 emerged 仅 在……之后 many copies were wired together:

  1. flip-flop modules retained the bits 的 a register;
  2. gate modules selected 和 combined register outputs;
  3. pulse 和 timing modules sequenced transfers;
  4. level converters 和 drivers connected the processor 到 内存 和 peripherals.

Modularity improved manufacturing 和 field repair because technicians could test and replace a card. It did 不 make modules instruction-set components: an ADD instruction depended 在 the combined datapath 和 control wiring across many cards.

PDP-1 作为架构背景 #

DEC announced the PDP-1 in 1959. Its 18-bit word, accumulator-centered design, core memory, 和 asynchronous peripheral interfaces established context 用于 later 18-bit PDP systems. 一个 standard 内存 held 4,096 words 和 用于 12-bit addresses. A memory-reference instruction contained an operation code, an indirect-address bit, and a 12-bit address; operate 和 I/O instructions encoded control functions instead of a normal 内存 address.

principal programmer-visible state included an 18-bit accumulator, an 18-bit I/O register, a program counter, 和 status 或 control flags. Thompson had first written the Space Travel program 在 Multics 和 then adapted it 到 the PDP-7. Filesystem experiments, an assembler, a shell, 和 a small set 的 utilities grew into an operating system.
