X.Org 项目托管于 https://gitlab.freedesktop.org/xorg/。xorg/xserver 项目构建 X 服务器可执行文件，包括 X 和 Xorg。xorg/app/xinit 项目构建 xinit 及其 startx 包装器。

启动会话 #

startx 调用 xinit，后者启动 X 服务器，然后启动客户端会话。如果没有显式的客户端脚本，它会使用约定的用户配置或系统默认值。服务器通常会创建本地 Unix 套接字，例如 /tmp/.X11-unix/X0，并设置相应的显示编号。桌面显示管理器执行大致相同的任务，但还会管理登录、座席和会话生命周期。

在当代 Linux 系统上，Xorg 通常不会以永久 root 权限启动。设备和座席访问通常由 logind 或等效的座席管理器进行协调；发行版打包方式决定受支持的启动路径。
