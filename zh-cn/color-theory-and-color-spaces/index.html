色彩理论与色彩空间

当软件需要将数字映射为可见输出时，色彩理论就具有实际意义。其底层物理过程很简单，但知觉模型并不简单。

视锥细胞响应 #

人类视觉使用三类视锥细胞，通常根据其对长、中、短波长的敏感性分别称为 L、M 和 S。

  • L 视锥细胞在约 564–580 nm 处响应最强。
  • M 视锥细胞在约 534–545 nm 处响应最强。
  • S 视锥细胞在约 420–440 nm 处响应最强。

不同人的视锥细胞分布存在差异，因此相同的光谱可能产生略有不同的知觉结果。L 视锥细胞和 M 视锥细胞的比例在个体之间差异很大，而 S 视锥细胞只占总数的一小部分，通常约为 2%。

大脑不会还原出单一波长，而是根据视锥细胞响应的模式和强度估计颜色。在理想条件下，人类视觉在紫外线区域可延伸到约 310 nm，在近红外线区域可延伸到 1100 nm，但这些边界并不明确。

加法混色 #

光源的光会相加。650 nm 的光束和 540 nm 的光束不会合并成一束具有平均波长的新光束；它们仍会以各自的波长刺激眼睛。

因此，两个不同的光谱可能看起来完全相同。知觉上的匹配不要求物理光谱完全一致，只要求视锥细胞的响应相同。

品红色是典型示例：它是有效的知觉颜色，但在可见光谱中并不存在对应的单一波长。

色彩空间 #

色彩空间是一种表示颜色值的坐标系，同时包含对色域和传递特性的定义。

sRGB #

sRGB 是 Web 和许多 UI 工具包的默认色彩空间。它基于 RGB 原色和一条非线性传递曲线，因此便于设备处理，但在知觉上并不均匀。

HSL #

HSL 将色相、饱和度和亮度分离开来，因此在“选择更偏红的颜色”或“降低鲜艳度”等任务中，比直接使用原始 RGB 更容易理解。代价是，数值上相等的步长并不对应知觉上相等的步长。

HSV #

HSV 类似于 HSL，但用明度或亮度取代了亮度。它通常适用于颜色选择器，因为它符合用户描述类似颜料的调整方式。

渐变 #

在 RGB 中进行线性插值很简单，但由于 RGB 在知觉上并不均匀，因此中间色经常显得浑浊。

如果目标是实现平滑的视觉过渡，那么插值空间比公式本身更重要。渐变应当在坐标轴更符合人类知觉的空间中进行评估，这样中间颜色才会显得间隔均匀。
