GNU Info 是用于阅读由 Texinfo 生成的手册的终端阅读器。它并非用于线性文本文件的 分页器：一个 Info 文件 包含由菜单、交叉引用以及 Next、Prev 和 Up 指针 连接起来的命名节点。已安装的手册可以拆分到文件系统中的多个压缩文件中，但 Info 会将其呈现为一本手册。

从手册树开始 #

不带参数运行 info 可打开目录节点，即已安装的手册树。运行 info coreutils 或 info '(coreutils)Top' 可打开指定的手册和节点。

sh 
info
info bash
info '(gitman)git-config'

参数语法为 '(file)node'；应将其引用起来，以免 shell 解释特殊字符。找不到手册 说明提供其 Info 文件的软件包尚未安装，或其 Info 目录不在搜索路径中。

遍历节点而非页面 #

使用节点结构进行定向阅读：

按键操作
n、p、u跟随 Next、Prev 或 Up 指针。
t、d转到手册的 Top 节点或目录节点。
m从当前菜单中选择一项。
f跟随交叉引用。
g按名称转到节点。
l沿已访问节点的历史记录返回。

n 和 p 按节点层次结构移动，而 [ 和 ] 按手册的节点顺序移动。应将前者 视为结构导航，将后者视为书籍式阅读；两者可能到达不同的节点。

阅读、搜索与返回 #

SPC 向前滚动，并可在到达末尾时继续到下一个节点；DEL 或 Backspace 向后 滚动。C-v 向前滚动但不会离开当前节点。b 和 e 移动到节点的开头和末尾。

使用 s 向前搜索，并再次按 s 重复搜索。i 搜索手册索引；对于命令或选项 名称，它往往比全文搜索更精确。跟随交叉引用后，使用 l 可沿节点历史记录返回。

按 H 查看阅读器内置的按键绑定帮助，按 q 退出。Info 使用 Emacs 风格的表示法： C-x 表示 Ctrl+x，M-x 表示 Meta+x。在将 Alt 映射为 Meta 的终端上，M-x 即 Alt+x。 M-x 还可以按名称运行命令，在终端或本地配置更改了按键绑定时很有用。

考虑阅读器差异 #

独立的 info 程序和 Emacs Info 采用相似的节点概念，但在按键绑定、显示、 自定义和鼠标行为方面可能有所不同。less 等分页器滚动的是字节流；Info 会保留 节点链接、菜单、历史记录和索引。使用 info --help、H 或已安装的 Info 手册， 确认当前系统上阅读器提供的按键绑定。
