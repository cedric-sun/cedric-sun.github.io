Android Open Source Project 的代码检出目录及其构建产物需要大量磁盘空间；确切需求取决于分支、目标以及启用的变体。请使用 64 位 Linux 主机，并确保其具备充足的 RAM、高速存储，以及同时容纳代码检出目录和输出目录所需的可用空间。

获取源代码 #

AOSP 分布在许多 Git 仓库中。repo 工具根据清单协调这些仓库；它是一个基于 Python 的 Git 封装工具，而不是独立的源代码管理系统。使用 repo init 初始化所需分支，然后使用 repo sync 填充或更新代码检出目录。

Android 的构建系统是 Soong。模块定义通常是 Android.bp Blueprint 文件；Soong 使用 Ninja 执行构建，而 Kati 支持其余的 Android Make 兼容层。运行 AOSP 环境设置脚本选择产品和构建变体，然后调用该分支文档中指定的构建目标。

运行镜像 #

仅在镜像和机器配置均受目标支持时，才使用模拟器或 QEMU。Android 产品与硬件相关：启动固件、内核、分区和设备配置必须相互匹配。对于通用的 x86_64 开发，Android Emulator 通常是受支持的选择；在试验兼容的内核、固件和磁盘布局时，QEMU 很有用。
