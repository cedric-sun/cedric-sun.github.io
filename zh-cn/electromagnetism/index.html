经典电磁学描述电场和磁场、它们的源、它们对物质施加的力以及它们的传播。当元件尺寸相对于相关波长很小时，电路模型可以近似描述这些场。高频互连需要场模型或传输线模型，因为电压和电流不再能同时在各处发生变化。

电荷、电流、场和力 #

电荷守恒。电荷密度 ρ 描述单位体积的电荷，而电流密度 J 描述单位面积的电荷流动。局部连续性关系为：

text 
∂ρ/∂t + ∇ · J = 0

无论电荷是否移动，电场 E 都会对其施加力。磁场 B 产生依赖速度的力。两者共同形成洛伦兹力：

text 
F = q(E + v × B)

磁力项垂直于速度，因此只改变方向，本身不做机械功。电场项可以向电荷传递能量或从电荷获取能量。在导体中，电场驱动载流子，从而产生电流；材料属性和几何形状决定最终的宏观电阻。

微分形式和积分形式的麦克斯韦方程 #

在真空中使用 SI 单位并包含源时，麦克斯韦方程为：

text 
∇ · E = ρ/ε₀                 ∮ E · dA = Qenclosed/ε₀
∇ · B = 0                    ∮ B · dA = 0
∇ × E = -∂B/∂t              ∮ E · dl = -dΦB/dt
∇ × B = μ₀J + μ₀ε₀∂E/∂t    ∮ B · dl = μ₀I + μ₀ε₀dΦE/dt

微分形式描述一点处的场行为。积分形式将闭合曲面或回路上的场与其中包含的电荷、电流或变化的通量联系起来。高斯电定律将电散度与电荷关联起来。高斯磁定律表明，在经典理论中磁通量没有源或汇。法拉第定律将环形电场与变化的磁通量联系起来。包含麦克斯韦位移电流项的安培定律将环形磁场与传导电流和变化的电通量联系起来。

在散度定理和斯托克斯定理所要求的正则条件下，积分方程由微分方程推出。界面边界条件可以通过使高斯曲面或回路跨越材料边界而收缩得到；表面电荷和表面电流随后可能在选定的场分量中产生不连续。

感应和电磁波 #

法拉第感应解释了发电机、变压器和电感器的工作原理。穿过电路的磁通量变化会产生电动势：

text 
emf = -dΦB/dt

负号表示楞次定律：感应响应会抵抗产生它的磁通量变化。互感通过共享磁通量耦合电路，而自感将电路变化的电流与其自身产生的感应电压联系起来。

在无源、均匀的真空中，对麦克斯韦方程取旋度可得：

text 
∇²E = μ₀ε₀ ∂²E/∂t²
∇²B = μ₀ε₀ ∂²B/∂t²

这些波动方程以 c = 1/√(μ₀ε₀) 的速度传播。真空中的平面波具有相互垂直的 E、B 和传播方向。材料的介电率、磁导率和电导率会改变相速度、衰减、反射和色散。

能量、坡印廷流和阻抗 #

真空电磁能量密度为：

text 
u = (ε₀|E|² + |B|²/μ₀) / 2

坡印廷矢量给出单位面积的功率流：

text 
S = E × H

坡印廷定理平衡场能量的减少、向外的能量通量以及对电荷所做的功。该模型对电路很有用，因为功率通过导体周围的场到达负载，而不是将电子视为以信号速度沿导线携带能量的包。

波阻抗关联电场和磁场的幅值。在真空中，Z₀ = √(μ₀/ε₀)，约为 377 欧姆。传输线则具有由导体几何形状和材料属性决定的特性阻抗。阻抗不匹配会导致反射；匹配源、线路和负载阻抗可以控制这些反射。

辐射和模型限制 #

加速电荷和随时间变化的电流分布可以产生辐射。天线几何形状决定近场如何与储存的电场能量和磁场能量耦合，也决定远场如何携带能量离开。惯性参考系中以恒定速度运动的电荷不会仅仅因为运动而辐射。

麦克斯韦方程是经典理论。狭义相对论描述惯性参考系之间电场和磁场的关系，而量子电动力学描述它们与物质的量子相互作用。
