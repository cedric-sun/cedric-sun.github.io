VNC 使用远程帧缓冲协议传输远程帧缓冲区和输入事件。它适用于隔离的图形桌面、通过浏览器提供的会话，以及不应接收主机显示套接字的容器工作负载。

服务器和虚拟显示器 #

Xvfb 是没有物理显示器的内存中 X 服务器。x11vnc 通过 VNC 共享现有的 X 显示；它本身不会创建虚拟桌面。其他 VNC 服务器（例如 TigerVNC 的 Xvnc）将 X 服务器与 VNC 端点结合起来。noVNC 是 WebSocket 到 VNC 的客户端，允许浏览器通过兼容的代理连接。

VNC 的身份验证和加密方式因实现而异。服务器只能通过经过身份验证且加密的通道暴露，常见方式包括 VPN、SSH 隧道，或带 TLS 和访问控制的网关。
