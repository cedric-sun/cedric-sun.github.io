電子回路の基礎

回路解析では、電界が電荷を移動させ、エネルギーを蓄積または散逸させる 仕組みをモデル化します。電圧は電位差、電流は単位時間当たりの電荷の流れ、 電力はエネルギー移動の速度です。

text 
V = I R
P = V I

オームの法則は線形抵抗に適用されるもので、すべての部品に適用されるわけでは ありません。実際の設計では、電圧、電流、電力、温度、周波数、および過渡現象 に関する定格も満たす必要があります。

抵抗、静電容量、インダクタンス #

抵抗器は電気エネルギーを熱として散逸させます。抵抗はオームで測定し、 その逆数であるコンダクタンスはジーメンスで測定します。抵抗率は材料の性質 ですが、部品の抵抗値は形状と温度にも依存します。

コンデンサーは電界にエネルギーを蓄えます。

text 
C = Q/V
i = C dv/dt
EC = C V²/2

理想モデルでは、コンデンサーの電圧は瞬時に変化できません。瞬時の変化には 無限大の電流が必要になるためです。直列 RC 回路では、時定数 τ = RC に 従って電圧が最終的な直流値へ指数関数的に近づきます。実際のコンデンサーには、 等価直列抵抗、漏れ、誘電吸収、および電圧や温度に依存する静電容量が加わります。

インダクターは磁界にエネルギーを蓄えます。

text 
v = L di/dt
EL = L I²/2

理想モデルでは、インダクターの電流は瞬時に変化できません。直列 RL 回路の 時定数は τ = L/R です。実際のインダクターには、巻線抵抗、寄生容量、コア損失、 および飽和電流の上限が加わります。誘導性電流を遮断すると大きな電圧が発生する 可能性があるため、コイルやリレーにはフライバックダイオードなどのクランプが 必要になる場合があります。

正弦波の角周波数 ω では、インピーダンスが抵抗とリアクタンスを組み合わせます。

text 
ZR = R
ZC = 1/(jωC)
ZL = jωL

したがって、大きさと位相は周波数によって変化します。理想的な直流定常状態では、 コンデンサーは開回路、インダクターは短絡として振る舞いますが、どちらの近似も 起動時や高周波での挙動を表しません。

キルヒホッフの電流則はノードにおける電流の収支を、キルヒホッフの電圧則は ループを一周する電位変化の収支を表します。テブナン等価回路とノートン等価回路は、 線形二端子回路網を電源とインピーダンスに簡約するため、負荷とバイアスの計算が 容易になります。

論理レベル、プル抵抗、ノイズマージン #

デジタル論理では、電圧範囲を論理0と論理1に対応付けます。データシートは、 入力ロー最大電圧 VIL、入力ハイ最小電圧 VIH、出力ロー最大電圧 VOL、 および出力ハイ最小電圧 VOH を規定します。最悪条件での直流ノイズマージンは 次のとおりです。

text 
low margin  = VIL(max) - VOL(max)
high margin = VOH(min) - VIH(min)

電源変動、グランドオフセット、クロストーク、終端、およびエッジ速度は、 利用可能なマージンを減少させます。TTL、LVTTL、CMOS、SSTLなどの ロジックファミリー名だけでは電気的互換性は保証されません。実際の入力、 出力、電流、およびタイミング仕様を比較してください。

駆動されていない入力の状態は保証されません。プルアップ抵抗または プルダウン抵抗は、アクティブドライバーが抵抗に優先できる状態を保ちながら、 既定のレベルを与えます。オープンドレイン出力とオープンコレクター出力には プルアップが必要であり、各デバイスはロー状態だけをアサートするため、 一つの線を共有できます。プッシュプル出力は両方の状態を能動的に駆動するため、 プロトコルがバス競合を防止しない限り、互いに接続してはなりません。

高インピーダンス出力は、共有バスからドライバーを電気的に切り離します。 RESET_n や CS# のようなアクティブローの名前は、アサート時の極性を 表すもので、電圧規格を表すものではありません。DDRのようなソース同期 インターフェイスでは、受信側のタイミングが遠方のシステムクロックだけでなく 相対的なエッジ位置に依存するため、データとともにストローブを配信します。

PN接合、ダイオード、整流 #

ドナー・ドーピングはn型シリコンに可動電子を供給し、アクセプター・ドーピングは p型シリコンに可動正孔を供給します。PN接合を横切る拡散によって固定された イオン化不純物が残り、空乏層と内蔵電界が形成されます。

順方向バイアスは接合障壁を下げ、大きな電流を流せるようにします。 逆方向バイアスは空乏層を広げ、降伏するまで漏れ電流を許容します。 一般的な定電圧ダイオードモデルは概算に有用ですが、ダイオード電流は接合電圧に 対して指数関数的に変化し、温度によっても大きく変化します。

半波整流器は、入力の一方の極性で導通します。ブリッジ整流器は両方の半周期を 使用しますが、導通経路に二つのダイオード電圧降下が入ります。平滑コンデンサーは ピーク間に負荷電流を供給してリップルを低減します。その結果生じるパルス電流に 合わせて、電源、ダイオード、コンデンサーのリップル定格、突入電流、および レギュレーターのすべてを選定する必要があります。

ツェナーダイオードとアバランシェダイオードは、クランプまたは基準電圧のために 意図的に逆方向降伏領域で動作します。降伏自体は電流を制限しないため、 直列インピーダンスが必要です。LEDはキャリア再結合を光に変換し、 フォトダイオードは吸収した光子を電流に変換します。分光感度とバイアス方法は、 デバイスの構造に依存します。

BJTとMOSFETの動作領域 #

NPNバイポーラ接合トランジスターには、遮断、順方向能動、飽和、および逆方向能動の 各領域があります。アナログ増幅では一般に、コレクター電流がベース・エミッター間 電圧に関係し、限られた範囲でベース電流の約 β 倍となる順方向能動動作に デバイスをバイアスします。スイッチングでは、トランジスターを遮断と飽和の間で 駆動します。β は電流、温度、およびデバイスによって変動するため、 スイッチ設計では強制ベース電流を使用し、飽和電圧と蓄積時間を確認します。

長チャネルモデルにおけるエンハンスメント型MOSFETには、遮断、三極管／線形、 および飽和の各領域があります。用語はBJTのスイッチングとは異なります。 閉じたスイッチとして使用するMOSFETは、MOSFETの飽和領域ではなく、 低抵抗の三極管領域で動作します。ゲートしきい値電圧は、導通開始時の データシート試験条件を示すだけであり、低いオン抵抗を保証しません。

MOSFETのゲートには直流電流がほとんど流れませんが、容量性負荷になります。 ドライバーは、スイッチング損失を制御できる速さで規定のゲート電荷を移動させる 必要があります。設計では、実際のゲート電圧における RDS(on)、ドレイン電圧と 電流の制限、安全動作領域、ボディーダイオードの挙動、熱抵抗、および スイッチング過渡現象を確認する必要があります。CMOSロジックはnチャネルと pチャネルのデバイスを組み合わせて静的電流を低減しますが、容量の充電によって 動的電力が発生します。

グランド、電源、測定の安全性 #

グランドは基準ノードであり、電流を吸収する無限のシンクではありません。 保護接地、シャーシ、アナロググランド、デジタルグランド、および信号リターンは それぞれ異なる役割を持ちます。帰還電流は最小インピーダンスの経路を流れますが、 高周波ではその経路が最小抵抗の経路と異なる場合があります。したがって、 レイアウトでは短い帰還経路を維持し、繊細な信号に大電流による電圧降下を 共有させないようにします。

電源入力には、電流制限、負荷ピン付近でのデカップリング、バルクエネルギー蓄積、 必要に応じた逆極性保護、および故障電流に合わせた導体が必要です。 ヒューズは配線を保護して火災リスクを低減しますが、高電圧回路を触れても 安全な状態にはしません。

回路をプロービングする前に、次を実施してください。

  • 電源に対するメーター、プローブ、絶縁、および測定カテゴリーの定格を確認する。
  • 活線測定が不要なら、電源を切り、蓄積されたエネルギーを放電する。
  • ベンチ型オシロスコープのプローブグランドは一般に保護接地へ接続されている。 活線ノードにクリップすると短絡が生じる可能性があることを考慮する。
  • フローティングノードまたはハイサイドノード用に設計された、差動または絶縁 測定方式を使用する。
  • 電流測定は直列接続で行い、接続前にメーターリードが正しいヒューズ付き入力に 挿入されていることを確認する。

商用電源、高エネルギーのバッテリー、および充電済みコンデンサーは、致命的な 感電、アーク、または火災を引き起こす可能性があります。このようなシステムには、 即席のブレッドボード作業ではなく、適用される安全規格、絶縁、および有資格者に よる手順が必要です。
