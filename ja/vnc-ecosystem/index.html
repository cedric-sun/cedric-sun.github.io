VNC は、Remote Framebuffer プロトコルを使用して、リモートのフレームバッファーと入力イベントを転送します。分離されたグラフィカルデスクトップ、ブラウザーから配信するセッション、ホストのディスプレイソケットを受け取るべきでないコンテナーワークロードに適しています。

サーバーと仮想ディスプレイ #

Xvfb は、物理ディスプレイを持たないメモリ内 X サーバーです。x11vnc は既存の X ディスプレイを VNC 経由で共有しますが、それ自体が仮想デスクトップを作成するわけではありません。TigerVNC の Xvnc など、他の VNC サーバーは、X サーバーと VNC エンドポイントを組み合わせます。noVNC は WebSocket から VNC へのクライアントであり、互換性のあるプロキシを経由してブラウザーから接続できます。

VNC の認証と暗号化は実装によって異なります。サーバーは、認証済みで暗号化されたチャネル、一般には VPN、SSH トンネル、または TLS とアクセス制御を備えたゲートウェイを通してのみ公開してください。
