VS Code の仮想スペース #

VS Code には、長年にわたって仮想スペースのサポートがありませんでした。Issue microsoft/vscode#13960 では、2016 年からこの機能が追跡され、最終的に 2024 年に解決されました。

Libtool による静的リンク #

LT_INIT は、プロジェクトがライブラリをビルドする方法を設定します。実行可能ファイルの最終的なリンカー モードを制御するものではありません。

libtool がリンク手順を実行すると、LDFLAGS=-static はコマンドラインに渡されます。ただし、推移的依存関係が共有オブジェクトとしてしか利用できない場合、完全に静的なバイナリになることは保証されません。

sh 
/bin/sh ../libtool --silent --tag=CC --mode=link gcc ... -static -o file file.o seccomp.o libmagic.la -lm -lz

有用な確認方法は次のとおりです。

  • make -d で実際のリンクコマンドを確認する。
  • 生成物に対して ldd を実行する。
  • 完全に静的な実行可能ファイルを想定する前に、必要なすべてのライブラリが静的アーカイブとして利用可能であることを確認する。
