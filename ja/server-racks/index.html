19 インチラックは、通信、コンピューティング、ネットワーク、オーディオ機器の前面パネルと取り付けジオメトリを標準化します。公称 19 インチ寸法は取り付け耳の間のパネル幅を表すだけであり、キャビネット幅、レール間隔、機器の奥行き、電力、冷却は指定しません。

ラックユニット、穴パターン、レール #

1 ラックユニット (U または RU) は 1.75 インチ (44.45 mm) です。1U の間隔には、垂直方向に 3 つの取り付け穴があります。中心間のパターンは、繰り返す前に 0.625 インチ、0.625 インチ、0.5 インチとなるため、狭い隙間によって隣接するラックユニット境界を識別できます。シャーシを境界をまたいで取り付けると後続のすべての設置がずれるため、レールには一貫して番号を付けます。

レールには、ケージナット付きの角穴、ねじなし丸穴、ねじ穴があります。工具不要のスライドレールハードウェアは、すべてのパターンで互換性があるわけではありません。4 ポストキャビネットは、前後のレールで奥行きのあるサーバーを支えます。2 ポストのリレーラックは浅い機器に適していますが、奥行きのある重いシャーシにはメーカー承認の棚またはセンターマウントキットが必要です。

機器の奥行きと、使用可能なキャビネットの奥行きは別の測定値です。次を確認します。

  • 前後のレール調整範囲。
  • コネクター、ケーブルの曲げ半径、電源コードを含むシャーシの奥行き。
  • ドア、ファン、ケーブル管理のクリアランス。
  • スライドレールの伸長とサービス位置。
  • サイドパネル、ゼロ U PDU、垂直ケーブルマネージャーによる障害物。

荷重、重心、固定 #

ラックの静的定格は、設置されて静止している場合に適用されます。動的定格または輸送定格は移動を考慮するため、はるかに低い場合があります。床荷重、キャスター、レベリングフット、上げ床タイル、耐震要件によって追加の制限が課されます。

重い機器は低い位置に設置します。重心が高いと転倒モーメントが増加するためです。ラックメーカーが別途指定しない限り、一度に 1 台のスライド式シャーシだけを伸ばします。取り付け耳は機器の位置を決めますが、全重量を支えられるとは限りません。必要なすべてのレール、後部サポート、ファスナーを取り付けます。

設置手順と地域の要件に従って、キャビネットを固定または安定化します。隣接ラックを連結すると位置合わせは改善できますが、固定が必要な場合に床または壁への固定の代わりにはなりません。機器を搭載したキャビネットを移動する前に、輸送荷重を個別に確認します。

電力分配と接地 #

電力計画は PDU のコンセント数ではなく分岐回路から始めます。定常負荷、起動または突入動作、電源効率、適用される電気規格が要求する連続負荷制限を計算します。機器銘板の最大値の合計を、回路または冷却設計が有効である証拠として扱わないでください。代表的なワークロードを測定し、文書化された余裕を確保します。

冗長なデバイス電源は、独立した障害ドメインに接続されている場合にのみ可用性を高めます。インフラストラクチャが許す場合は、別々のラック PDU、分岐回路、UPS 経路、上流電源から供給します。生き残ったどちらの経路でもフェイルオーバー負荷を処理できることを確認します。計測 PDU は電流または電力を公開し、スイッチ PDU は制御されたコンセント操作も可能にします。

UPS は停止を橋渡しし、設計上の制限内で電力を調整します。稼働時間は実負荷、バッテリーの状態、温度、変換モードによって異なります。発電機と自動切替スイッチは長時間の事象に対応しますが、独自の切替と保守動作をもたらします。

保護接地は露出した導電部を結合し、障害時に保護装置が動作するようにします。ラックと施設の接地設計に従ってください。信号リファレンスと保護接地は互換ではありません。データパスのノイズ問題を解決するために安全接地を取り外さないでください。

エアフローと熱管理 #

ほとんどのサーバーとネットワーク機器は前面から背面へのエアフローを使用しますが、逆方向のエアフローに対応するネットワーク機器もあります。方向を混在させると、高温の排気が吸気へ再循環する可能性があります。列と封じ込めを、冷たい供給空気が吸気に届き、高温の空気が短絡せずに戻るように配置します。

ブランキングパネルは未使用のラックユニット開口部を閉じます。開いた隙間は排気の再循環を許すためです。ブラシパネルと密閉された床開口部は、ケーブル周りのバイパスを減らします。キャビネットドアには十分な自由面積が必要で、フィルターには保守間隔が必要です。ラック入口温度は、室内平均温度よりも局所的なホットスポットの検出に有用です。

冷却容量は電気的な熱負荷に一致させます。入力電力のほぼすべてが室内の熱になります。高密度機器は、物理スペースや PDU コンセントを使い切る前に、ラックの計画熱容量を超える可能性があります。入口温度、ファン状態、スロットリング、PDU 負荷をまとめて監視します。

配線、サービスクリアランス、ラベル #

可能な場合は電力とデータの経路を分離し、光ファイバーと銅線の曲げ半径を守り、ケーブルをファンの吸気口やスライド機構から遠ざけます。ケーブル管理アームには、コネクターを引っ張らずに完全に伸ばせるだけの余裕が必要です。余分なケーブルはエアフロー経路に詰め込まず、予測可能な方法で配線します。

ドア、クラッシュカート、吊り上げ装置、コンポーネント交換のために、前後のクリアランスを確保します。一部のサーバーでは内部部品の交換に完全な引き出しが必要なため、通路幅とラックの固定は保守性の一部です。

電源、ネットワーク、ストレージ、コンソール接続の両端に、安定した識別子でラベルを付けます。ラック、ユニット位置、デバイス、ポート、PDU コンセント、上流回路をインベントリに記録します。ラックユニット座標は物理的な配置を表すものであり、電気、ネットワーク、依存関係の文書化の代わりにはなりません。
