util-linux は、独立した上流プロジェクトとして保守されているシステムユーティリティの集合です。ブロックデバイス、マウント、端末、セッション、名前空間、リソース制御、データ整形のためのインターフェースを提供します。ディストリビューションはユーティリティを個別のパッケージに分割できるため、インストールされるコマンドはパッケージングポリシーによって異なります。

運用上の境界 #

パーティション、マウント、スワップ、デバイス状態、プロセス資格情報、名前空間を変更するコマンドには、適切な権限が必要です。変更する前に状態を確認し、UUID や /dev/disk/by-id などの安定した属性でデバイスを識別し、対象がマウントされていないこと、またアクティブに使用されていないことを確認してください。

このプロジェクトは、複数のカーネルインターフェースにまたがっています。

  • lsblk、blkid、blockdev、fdisk、wipefs は sysfs、デバイス ノード、ioctl、ディスク上のシグネチャを調べます。
  • mount、umount、findmnt、fsfreeze は VFS マウント API と /proc/self/mountinfo を操作します。
  • unshare、nsenter、setpriv、prlimit、taskset、chrt は、 プロセスの名前空間、資格情報、リソース制限、アフィニティ、スケジューラを設定します。
  • agetty、script、setterm、wall は端末とログイン記録を操作します。

正確なコマンドセットは、util-linux のビルド構成とディストリビューションのパッケージングによって異なります。最近追加されたオプションに依存する前に、command --help、コマンドの man ページ、ディストリビューションのパッケージメタデータ、または個々のコマンドの --version 出力を確認してください。

一般的なワークフロー #

lsblk --fs、blkid、findmnt、mountpoint は、ストレージを変更せずに調査します。

sh 
lsblk --json --output NAME,PATH,SIZE,FSTYPE,UUID,MOUNTPOINTS
findmnt --json --output SOURCE,TARGET,FSTYPE,OPTIONS
blkid --probe --usages filesystem /dev/disk/by-id/example

util-linux が情報を追加するとデフォルト出力は変わるため、スクリプトでは列を明示してください。サポートされている場合は --json、--pairs、--raw を優先し、人間向けの診断メッセージを解析する場合は LC_ALL=C を設定します。整列されたデフォルトテーブルを安定したインターフェースとして解析してはなりません。

fdisk、cfdisk、sfdisk はパーティションテーブルを変更します。sfdisk --dump で現在のレイアウトを保存し、書き込み前にサイズ、モデル、シリアル番号、安定したパスでデバイスを検証してください。意図したテーブル変更後に、partx はパーティションマッピングの追加または削除をカーネルに要求します。ディスク上のテーブル自体は編集しません。mkswap はスワップ領域を準備し、swapon が有効化し、swapoff が無効化します。

unshare、nsenter、setpriv、runuser、setarch、taskset は実行コンテキストに影響します。名前空間やアフィニティを変更しても権限は付与されません。プロセスが実行できる操作は、引き続きケーパビリティ、ユーザーマッピング、cgroup ポリシーによって決まります。

sh 
unshare --user --map-root-user --mount-proc sh
nsenter --target "$pid" --mount --uts --ipc --net --pid
script --log-out session.typescript --log-timing session.timing

nsenter は既存プロセスが使用する選択した名前空間に参加するため、それらを調査して参加する権限が必要です。非特権ユーザー名前空間での unshare の利用可否は、カーネルとローカルセキュリティポリシーによって制御されます。

script、scriptreplay、scriptlive は端末セッションを取得できます。記録された入力には資格情報やその他の秘密情報が含まれる可能性があるため、ファイルには内容に応じたアクセス制御が必要です。
