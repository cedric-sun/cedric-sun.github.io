ソフトウェアが数値を目に見える出力へ対応付ける必要が生じると、色理論は実用的になる。基礎となる物理現象は単純だが、知覚モデルは単純ではない。

錐体細胞の応答 #

人間の視覚では、長・中・短波長に対する感度にちなんで、通常 L、M、S と呼ばれる3種類の錐体細胞が使われる。

  • L 錐体は、およそ 564–580 nm 付近で最も強く応答する。
  • M 錐体は、およそ 534–545 nm 付近で最も強く応答する。
  • S 錐体は、およそ 420–440 nm 付近で最も強く応答する。

錐体細胞の分布には個人差があるため、同じスペクトルでも知覚結果はわずかに異なる可能性がある。L 錐体と M 錐体の比率は個人間で大きく異なる一方、S 錐体は全体のごく一部しか占めず、多くの場合は約 2% である。

脳は単一の波長を復元するのではなく、錐体細胞の応答パターンと強度から色を推定する。最適な条件では、人間の視覚は紫外線領域でおよそ 310 nm、近赤外線領域で 1100 nm まで及ぶ可能性があるが、これらの限界は明確な境界ではない。

加法混色 #

光源の光は加算される。650 nm の光線と 540 nm の光線を合わせても、平均波長を持つ新しい光線になるわけではなく、それぞれの波長で眼を刺激し続ける。

そのため、異なる2つのスペクトルが同じように見えることがある。知覚上の一致に物理スペクトルの一致は必要なく、錐体細胞の応答が同一であればよい。

マゼンタは典型的な例である。マゼンタは知覚上有効な色だが、可視スペクトル上の単一波長ではない。

色空間 #

色空間とは、色値の座標系であり、同時に色域と伝達特性の定義でもある。

sRGB #

sRGB は、Web および多くの UI ツールキットにおけるデフォルトの色空間である。RGB の原色と非線形の伝達曲線に基づいているため、デバイスには扱いやすいが、知覚的には均一ではない。

HSL #

  • sRGB の伝達特性と色域の定義
  • CIE の錐体細胞応答データ
