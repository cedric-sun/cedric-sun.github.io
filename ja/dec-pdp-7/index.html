DEC モジュールと PDP-7

Digital Equipment Corporation (DEC) は、カスタムのモノリシックプロセッサーボードではなく、カタログ化された論理モジュールから最初のコンピューターを構築しました。モジュールのパッケージは、研究所製品、System Modules、FLIP CHIP カードの間で大きく変化しましたが、工学的な方法は共通していました。標準化されたゲート、フリップフロップ、パルス回路、ドライバーを、配線されたバックプレーンを通じて組み合わせたのです。

Laboratory Modules #

DEC は 1950 年代後半、デジタル実験と制御システム向けに Laboratory Modules を導入しました。金属製の筐体にトランジスター回路を収め、前面にはバナナプラグ接続を備えていました。技術者はベンチ上でモジュールをパッチ接続したり、ラックシャーシに取り付けたりできました。カタログには、異なるスイッチング速度向けのファミリーとして、インバーター、フリップフロップ、パルス増幅器、遅延、クロック、電源などの機能ブロックが用意されていました。

テスト済みの回路を再利用可能なブロックとしてパッケージ化すると、各設置で必要なトランジスターレベル設計の量を減らせました。しかし前面パネルでのパッチ接続はかさばったため、数百個の反復論理機能を含むプロセッサーよりも研究所に適した形式でした。

System Modules から FLIP CHIP へ #

後に System Modules と呼ばれた System Building Blocks は、回路をエッジコネクター付きの小型カードに移しました。カードはワイヤラップされたバックプレーンのソケットに差し込み、ポイントツーポイントの配線がピンをレジスター、カウンター、バス、制御経路へ接続しました。この文脈での「バックプレーン」とは、標準化されたバスを載せた現代的な多層プリント基板ではなく、コネクターのフィールドとその配線を意味します。

FLIP CHIP のパッケージも、より小型なカードとバックプレーンの方式を継続しました。DEC は、論理、タイミング、周辺インターフェイス向けに電気的に異なる複数のシリーズを製造しました。色付きの取り外しハンドルと印刷された型番は技術者がモジュールを見つけるのに役立ち、保守文書はモジュールピン間の信号を追跡しました。カタログ上の 1 ユニットは数個のゲートまたは 1 ビットのレジスターを実装するだけだったため、完全なプロセッサー機能は多くのコピーを配線した後に初めて現れました。

  1. フリップフロップモジュールがレジスターのビットを保持する。
  2. ゲートモジュールがレジスター出力を選択して組み合わせる。
  3. パルスおよびタイミングモジュールが転送を順序付ける。
  4. レベルコンバーターとドライバーがプロセッサーをメモリと周辺機器に接続する。

モジュール化は、技術者がカードをテストして交換できるため、製造と現場修理を改善しました。しかし、モジュールが命令セットのコンポーネントになったわけではありません。ADD 命令は、多数のカードにまたがるデータパスと制御配線の組み合わせに依存していました。

アーキテクチャの文脈としての PDP-1 #

DEC は 1959 年に PDP-1 を発表しました。18 ビットワード、アキュムレーター中心の設計、コアメモリ、非同期周辺インターフェイスは、後の 18 ビット PDP システムの文脈を確立しました。標準メモリは 4,096 ワードを保持し、12 ビットアドレスを使用しました。メモリ参照命令には、オペレーションコード、間接アドレスビット、12 ビットアドレスが含まれました。operate 命令と I/O 命令は、通常のメモリアドレスではなく制御機能を符号化しました。

プログラマーから見える主な状態には、18 ビットアキュムレーター、18 ビット I/O レジスター、プログラムカウンター、ステータスまたは制御フラグが含まれていました。紙テープ、コンソールタイプライター、Type 30 精密ディスプレイは特徴的な周辺機器でした。Spacewar! などの対話型グラフィックスプログラムは、DEC の比較的アクセスしやすい対話型マシンがバッチ指向のコンピューター利用と異なる理由を示しましたが、PDP-1 はなお複数の機器ラックを占有しました。

PDP-7 のワード、命令、メモリ #

DEC は 1964 年に別の 18 ビットマシンとして PDP-7 を導入しました。その基本の同時電流コアメモリは、1.75 µs のサイクルで 4,096 ワードを保持し、拡張可能でした。プロセッサーは 1 の補数算術を使用し、アキュムレーターと算術・シフト用の 1 ビットのリンクを備えていました。

DEC が文書化した重要な内部レジスターには次のものがあります。

レジスター幅目的
AC18 ビット算術および論理アキュムレーター
L1 ビット算術およびシフト操作で使用するリンク
MB18 ビットメモリとの間で移動するワード
MA13 ビット基本メモリシステムに提示するアドレス
PC13 ビット次の命令のアドレス
IR4 ビット主命令オペレーションコード

メモリ参照ワードは、主操作に 4 ビット、間接指定に 1 ビット、アドレスフィールドに 13 ビットを割り当てます。メモリ拡張ハードウェアは、直接選択されたフィールドを超えるアクセスを提供しました。命令セットには周辺操作用の IOT ワードと、選択された互換プロセッサー機能を有効にするマイクロプログラム式の OPR ワードも含まれていました。したがって、すべての 18 ビットパターンが同じ方法でオペコードとメモリアドレスに分割されるわけではありません。

命令実行は、モジュールのタイミングチェーンで実装されたフェッチサイクルと実行サイクルを通じて進みました。間接参照では、プロセッサーは最初に実効アドレスをフェッチしました。メモリ操作では、メモリアドレスレジスターとバッファーレジスターがコアメモリサイクルを仲介しました。アーキテクチャは、ハードウェア診断を支援するために、これらの段階の十分な部分をコンソールと保守インターフェイスに公開しました。

メモリマップドレジスターなしの I/O #

PDP-7 の周辺機器は、通常のメモリマップドデバイスレジスターではなく、マシンの I/O システムを通じて通信しました。IOT 命令はデバイスを選択し、そのインターフェイスに属する解釈のパルスを発行しました。プログラムフラグと割り込み機能により、ソフトウェアは完了を待機または応答できました。

基本構成は紙テープとテレプリンター機器をサポートしました。オプションのコントローラーは、ディスプレイ、磁気テープ、その他のデバイスを接続しました。したがって、デバイスの速度とプロトコルは接続されたコントローラーに依存し、18 ビットのプロセッサーワードは、すべての周辺機器が一度に 18 個の有効ビットを転送することを意味しません。

PDP-7 と初期 Unix #

Bell Labs は別の研究のために PDP-7 を取得し、Ken Thompson は 1969 年に、そのままでは十分に利用されていなかったマシンを使って最初の Unix システムを実装しました。Thompson は最初に Multics 上で Space Travel プログラムを書き、その後 PDP-7 に適応させました。ファイルシステムの実験、アセンブラー、シェル、小さなユーティリティ群がオペレーティングシステムへ成長しました。Dennis Ritchie と Bell Labs の他の研究者が開発に加わりました。

初期 Unix は PDP-7 アセンブリーで書かれ、マシンの小さなコアメモリによる制約を受けました。よく知られた C への移行は、プロジェクトが PDP-11 に移った後に起こりました。したがって PDP-7 との関係はコードの起源に関する事実であり、後の Unix が PDP-7 の命令セットやモジュール構成を保持した証拠ではありません。
