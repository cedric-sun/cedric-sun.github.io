GNU Infoは、Texinfoから生成されたマニュアルを端末で読むためのプログラムである。線形なテキストファイルを表示するページャーではない。Infoのfileは、メニュー、相互参照、Next、Prev、Upポインターによって接続された名前付きノードを格納する。インストールされたマニュアルは、ファイルシステム上で複数の圧縮ファイルに分割されている場合があるが、Infoはそれらを1つのマニュアルとして表示する。

マニュアルツリーから始める #

引数なしでinfoを実行すると、インストール済みマニュアルのツリーであるディレクトリノードが開く。名前を指定したマニュアルとノードを開くには、info coreutilsまたはinfo '(coreutils)Top'を実行する。

sh 
info
info bash
info '(gitman)git-config'

引数の構文は'(file)node'である。シェルが特殊文字を解釈しないように引用符で囲む。マニュアルが見つからない場合は、そのInfoファイルを提供するパッケージがインストールされていないか、Infoディレクトリが検索パスに含まれていない。

ページではなくノードをたどる #

目的に沿って読むには、ノード構造を使用する。

キー操作
n, p, uNext、Prev、Upポインターをたどる。
t, dマニュアルのTopノードまたはディレクトリノードに移動する。
m現在のメニューから項目を選択する。
f相互参照をたどる。
g名前を指定してノードに移動する。
l訪問したノードの履歴を戻る。

nとpはノード階層をたどるのに対し、[と]はマニュアルの連続的なノード順に移動する。前者は構造をたどる操作、後者は書籍のように読み進める操作として扱う。両者は異なるノードに到達する場合がある。

読む、検索する、戻る #

SPCは前方にスクロールし、ノードの末尾では次のノードへ進む場合がある。DELまたはBackspaceは後方にスクロールする。C-vは現在のノードを離れずに前方へスクロールする。bとeはノードの先頭と末尾へ移動する。

前方検索にはsを使用し、検索を繰り返す場合もsを使用する。iはマニュアルの索引を検索する。コマンド名やオプション名を探す場合、索引は全文検索よりも正確であることが多い。相互参照をたどった後にlを使用すると、ノード履歴を戻る。

リーダーに組み込まれたキーバインドのヘルプを表示するにはH、終了するにはqを押す。InfoはEmacs形式の表記を使用する。C-xはCtrl+x、M-xはMeta+xを意味する。AltをMetaに割り当てる端末では、M-xはAlt+xである。 M-xは名前を指定してコマンドを実行する機能も持ち、端末やローカル設定によってキーバインドが変更されている場合に役立つ。

リーダー間の違いを考慮する #

スタンドアロンのinfoプログラムとEmacs Infoは同様のノード概念を提供するが、キーバインド、表示、カスタマイズ、マウス操作が異なる場合がある。lessなどのページャーはバイトストリームをスクロールする。一方、Infoはノードのリンク、メニュー、履歴、索引を保持する。現在のシステムのリーダーが提供するキーバインドを確認するには、info --help、H、またはインストール済みのInfoマニュアルを使用する。
