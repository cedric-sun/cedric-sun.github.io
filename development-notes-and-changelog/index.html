VS Code Virtual Space #

VS Code lacked virtual-space support for years. Issue microsoft/vscode#13960 tracked the feature from 2016 until it was finally resolved in 2024.

Static Linking with Libtool #

LT_INIT configures how a project builds its libraries. It does not control the final linker mode for an executable.

When libtool drives the link step, LDFLAGS=-static is forwarded into the command line, but that does not guarantee a fully static binary if the transitive dependencies are only available as shared objects.

sh 
/bin/sh ../libtool --silent --tag=CC --mode=link gcc ... -static -o file file.o seccomp.o libmagic.la -lm -lz

The useful checks are:

  • inspect the actual link command with make -d;
  • run ldd on the result;
  • verify that every required library is available as a static archive before expecting a fully static executable.
